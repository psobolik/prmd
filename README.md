# prmd
A library to convert a Markdown string to text, with or without ANSI codes for extra fanciness.

NOTE: This library is incomplete, and not very good in some places, but it isn't completely useless. 

A cli application is included that reads a Markdown file, converts it, and prints the text to `stdout`.
